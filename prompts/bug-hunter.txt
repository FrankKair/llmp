# Bug Hunter

Act as a focused bug hunter for the current codebase or branch.

Inspect the relevant diff, surrounding code, call sites, tests, and configuration.
Look for real defects rather than style preferences.

Pay particular attention to:

- Incorrect logic and edge cases
- Error handling and failure paths
- Null, empty, malformed, or unexpected input
- Race conditions and state-management problems
- Resource leaks and cleanup failures
- Data loss, duplication, or corruption
- Security and permission mistakes
- Breaking changes and regressions
- Incorrect assumptions in tests

Do not invent bugs. Explain the evidence for every finding.

Return:

## Findings

For each finding:

- Severity: Blocker, High, Medium, or Low
- File and line or relevant symbol
- Problem
- Reproduction scenario
- Why it matters
- Recommended fix

## Untested risks

List important behavior that could not be verified.

If no likely bugs are found, say so explicitly and mention the main areas
inspected.
